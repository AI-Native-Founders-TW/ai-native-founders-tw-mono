# Threads 已送出邀請帳號

本檔為 Threads 引流招募客服「已送出公版私訊邀請帳號」的唯一 truth，供發送前去重與發送成功後更新。本表記錄帳號與邀請狀態；私訊內容、聯絡資料及截圖證據另外保存在有權限的私人位置，不貼進本表。

## 核對與更新

1. 發送前查本表，Threads 帳號去除 `@` 並轉小寫作為唯一鍵；同一帳號只記一筆已送出邀請。
2. 只有回讀證實公版私訊邀請已送出成功，才新增帳號、送出時間、回讀確認結果及記錄者，並另存私人證據。
3. 結果不明先回讀確認，不記為已送出，也不盲目重送。
4. 已送出邀請不等於已加入 Discord、已提交申請或已取得成員資格。
