## 怎麼把自己加進來

### 寫程式

commit 進本 repo 或 mono，下次建置自動出現。

### 設計、文案、討論

在 PR 裡順手把自己加進 src/content/credits.yml 的 website.roles。

### 頭像

在 credits.yml 填上你的 GitHub 帳號，就會換成 GitHub 頭像。

### 名字對不上

同一個人有不同稱呼時，在 credits.yml 的 aliases 合併。
