# 加入頁文案

文案來源：[join.zh-tw.yaml](<../../../modules/ai-native-founders-tw-web/src/content/copy/join.zh-tw.yaml>)。本頁按敘述順序閱讀；共用頁首頁尾見 [landing-page 入口](<README.md#共用頁首與頁尾>)。

## 一份真誠的自介，就是你的起點。

以符合要求的自介 PR 申請，審查通過後取得成員資格。我們看的是真誠，不是背景、實力或經歷；沒有專案、還在探索，也可以如實寫。

加入不需付費；審查看真誠，不看背景。自介須附一張本人願意公開的真人照片，並自行選擇至少一個 R&R 當 Contributors，在 assignment 記錄選擇並連到自己的成員檔案；選擇分工不等於接受指定工作。

行動入口：「開始寫自介」「先讀申請制度」。頁面導覽標示為「Join · 加入路線」。

## 四步，跑完加入路線。

Star 與活動留言歡迎依意願參與；成員資格以自介 PR 審查通過為準。

1. 加入 Discord。大家交流、參與活動與找人協作的地方。Discord 是邀請，不是門檻。
2. 到 GitHub 按一顆 Star。用 Star 支持開源筆記，也方便之後找回來。
3. 讀三份文件。創辦人的話、憲法、申請制度：我們想做什麼、共同遵守的原則、怎麼加入。三個文件入口分別標示「創辦人的話」「憲法」「申請制度」。
4. 用 PR 提交自我介紹。寫下你是誰、為什麼加入、想要獲得什麼、想分享什麼，以及可以幫什麼忙、想要幫什麼忙。審查通過後，就是成員。

路線導覽標示為「Route · 四個檢查點」，一般入口使用「前往」，終點入口使用「開始寫自介」。

## 照著範本，一欄一欄寫。

這裡協助你起草自介，右邊會即時產生 Markdown。提交前請依 members/README 與正式申請制度核對最新要求並補齊內容；寫好後按下按鈕，GitHub 會開啟建立檔案的頁面，由你自己確認並開 PR。

產生器只在你的瀏覽器裡執行，不會把內容送到任何地方。草稿只存在這個瀏覽器；按下按鈕時，內容才會帶到 GitHub 的編輯頁，在你提交之前都不會公開。

### 關於你

「名字或慣用稱呼」的範例是「小明、Ray 貓」。「GitHub 帳號」為必填，欄位提示為「your-github」。必填目前使用的 GitHub 帳號。申請檔名為 `pending-<小寫帳號>.md`；合併前由合併人配置固定六位數編號，並改成 `<編號>-<小寫帳號>.md`。取得編號不代表取得正式成員資格。

「我是誰」的範例是「中文系大三，最近在想怎麼把寫作變成產品……」。「其他聯絡方式或作品連結」為選填，只填你願意公開的內容，連結欄位提示為「https://」。

### 為什麼加入

這一段分別詢問「為什麼想加入」「想要獲得什麼」「想分享什麼」。

### 可以幫什麼忙、想要幫什麼忙

寫下可以幫什麼忙、想要幫什麼忙，方便大家找人協作；這不代表你答應接下任何指定的工作。完整自介與分工要求，請依 members/README 與正式申請制度辦理。

「可以幫什麼忙」提供「文案校稿」「使用者訪談」兩個範例；「想要幫什麼忙」提供「一起整理開源筆記」「協助辦活動」兩個範例。

### 預覽、本人 review 與提交

提交前請由你本人 review 全文，確認內容都是真的，也沒有不願公開的個資。完整要求見 members/README 的提交步驟。

本人確認文字為：「我已經親自 review 全文，內容真實，也沒有不願公開的個資。」

提交入口為「到 GitHub 建立自介檔案」。會在新分頁開啟 GitHub（需要登入）。沒有權限時，GitHub 會自動幫你 fork；接著照頁面按「Propose new file」→「Create pull request」。

內容很長，GitHub 可能帶不進全文。若頁面是空的，請先複製 Markdown 再貼上。

也提供「想手動操作？看 members/README 的步驟」。

產生器的導覽名稱為「Intro builder · 自介產生器」。預覽區使用「預覽」「已完成」「還沒填」；操作按鈕為「複製 Markdown」「清空」，複製後顯示「已複製」，清空前詢問「確定要清空所有欄位嗎？」

## 你可能想問的。

### 我沒有經歷、沒有專案，可以加入嗎？

可以。我們不以背景、實力或經歷作為加入條件，只看意圖。自介真誠、值得信任，但沒有經歷、沒有專案的人，可以加入；還在探索創業志向，也可以如實說明。

依據入口：憲法、申請制度。

### 自介可以用 AI 寫嗎？

可以，自介由 AI 寫是很正常的；審查看的是內容有沒有真誠，不看文章品質。提交前請你本人 review 全文，確認沒有 AI 編造的經歷或參與承諾，也沒有不願公開的個資。

依據入口：申請制度、members/README。

### 加入 Discord 就算成員嗎？

不算。成員資格以自介 PR 審查通過為準。Discord 是大家交流、參與活動與找人協作的地方，我們會邀請你，但它不是門檻；Star 與活動留言也一樣，依意願參與。

依據入口：申請制度。

### 加入後一定要幫忙嗎？

不用。所有成員都是志工，組織不強制任何人承擔工作。基本參與度與分工安排依正式成員參與制度辦理；自介寫下可以幫什麼忙、想要幫什麼忙，不代表答應接下任何指定的工作。

依據入口：憲法、成員參與制度。

### 加入要收費嗎？

不用。以符合要求的自介 PR 申請，審查通過後取得成員資格。我們也不在筆記或活動中收錢置入、不為任何公司推銷。

依據入口：申請制度、憲法。

### 我不會用 GitHub 怎麼辦？

請依 members/README 的最新步驟與提交位置建立自介、開 PR。也可以用上面的自介產生器起草，再依正式要求核對與補齊。卡住了，就到 Discord 發問。

依據入口：members/README、Discord。

### 審查多久？誰審？

審查人、程序與權限安排依正式申請制度辦理，本頁不承諾處理時間。PR 送出就是提出申請；如果需要補充，你會在 PR 上看到審查意見。

依據入口：申請制度、自介審查。

活動入口為「留下問題」，狀態標示「正在進行」；頁面另提供「Credits →」。
