## 共用頁首與頁尾

品牌名稱為「AI-Native Global Founders Speedrun Taiwan」。品牌說明為「探索 AI-Native 創業的最佳實踐，將國際經驗與資源帶回臺灣。」

頁首提供「中」「EN」語言切換與「加入」入口。頁尾提供「探索」「加入」「Credits」「llms.txt」，社群入口為「Discord」與「GitHub · mono」，另有「這個網站也是開源的」及「回到起點」。

頁尾署名與性質說明為「非營利組織 · 開源筆記」「Logo by Sun」「部分視覺素材與程式由 AI 協作產生」。

## 維護方式與範圍

正文沿用現行文案的敘述、限定與語氣；同一標題下的連續文字整理為段落，真正並列的項目才用清單。合併重複控制文字、移除純版面定位標籤時，不得刪掉條件、承諾、問題、表單要求或例外。新增或修改對外主張仍須有來源及採納依據。

網站文案來源為網站 repo 的繁體中文 YAML，共用入口依頁首與頁尾元件，署名資料依 Credits 來源。動態人數與名單應由實際資料產生，本文不填假數字或假人名。

這次只調整文案文件的呈現與位置；不因此宣稱網站已同步。文案與現行制度的既有差異，見 [Kickoff](<../../../plans/001-Kickoff/plan.md#2026-10-29-文案萃取修正>)。
