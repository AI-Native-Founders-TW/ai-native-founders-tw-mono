## 探索 AI-Native 創業的最佳實踐，將國際經驗與資源帶回臺灣。

由臺灣創業者自發成立的非營利社群。與已成功出海的創業者進行經驗交流，透過建立開源的 AI Skills 來系統化地傳承知識，讓臺灣創業者都能用一步之遙在全球創造成功。

## 一起探索，臺灣創業者如何在全球創造成功。

從「臺灣出海創業者須知 101（出海創業入門）」開始，了解自己在哪個階段、該專注什麼。與已成功出海的創業者交流，把創業的戰術策略、成功與失敗故事，整理成開源的 Agent Skills，系統化地傳承知識。

### 開源的 Agent Skills 與創業問題

以下九個知識方向各對應一個創業者正在面對的問題：

- 臺灣出海創業者須知 101（出海創業入門）：我在哪個創業階段，現在最該驗證什麼？
- Founder-market fit：為什麼是我來做這個市場？
- AI-Native 創業的實踐：哪個工作流程值得客戶付費？
- 去美國立即可用的資源：去美國前，哪些資源能幫我接觸第一批客戶？
- Funding plan 的戰術策略：這輪資金要換到什麼里程碑？
- Pitch deck 的撰寫方式：為什麼是現在，憑什麼是我們？
- 矽谷 networking 的戰術模式：一次交流後，如何建立長期互信？
- 融入美國文化、培養自信：如何有自信地表達，也聽懂回饋？
- 每一年出海的成功與失敗故事：哪些經驗可複製，哪些有條件？

## 從臺灣出發，在矽谷持續成長。

從取得市場驗證、規劃資金，到建立人脈、落地矽谷。我們一起整理每個階段的戰術策略與前輩經驗，讓臺灣創業者知道自己在哪個階段、接下來該專注什麼。

臺灣 → 市場驗證 → 資金規劃 → 建立人脈 → 落地矽谷 → 在矽谷持續成長。

市場驗證：用客戶的使用、付費與留存，確認產品是否有市場需求。資金規劃：下一階段要達成什麼？需要多少資金、能支撐多久？

建立人脈：與客戶、創業者及投資人建立長期關係，讓交流有後續。落地矽谷：安排生活與工作、適應文化，讓事業能在當地持續經營。

一起交流各階段的戰術策略，整理成開源的 Agent Skills。人脈與資金規劃可以同時進行；我們不承諾引薦或媒合。

## 一起鑽研 AI-Native，讓臺灣持續走出面向全球的創業者。

通用型人工智慧 (AGI) 也許即將誕生。對想在全球創業的臺灣人而言，現在就是一起鑽研 AI、提升實踐能力的時刻。我們從組織本身、產品本身，到產品的設計和開發，探索 AI-Native 如何解鎖創業者的潛能。

### 組織本身

這個組織本身的協作方式，就大量採用 shared context 加上 AI-Native 的經營及開發方式。歡迎大家在參與這個組織的過程中，一起學習 AI-Native 如何幫助一個組織進行一定程度的去中心化。這樣能讓大家隨時提出自己的企劃和貢獻，把規格、計畫、知識都放在共同的 mono repo 與共同脈絡裡，讓 AI 協助大家把組織運作得更有效率。

### 產品本身

鼓勵大家開發 AI-Native 的產品，在各個領域打造 Agent as a Service，透過 AI 達成卓越的智慧成效，一起做出能在全球競爭的產品。

### 產品的設計和開發

一起鑽研如何用 AI-Native 的方式，從市場調查、產品設計、Pitch Deck、Funding Plan 到規格驅動開發，讓 founding team 熟悉整套 AI-Native 的產品設計及開發方式。透過 AI 放大自己的資訊組織效率，做到放大人類百倍的潛能，以此卓越的方法論彎道超車。

一起鑽研，共同實踐。

### 讓臺灣持續輸出 AI-Native founders。

透過持續交流與共同實踐，提升臺灣創業者運用 AI 的能力，讓更多人具備出海競爭力，也帶動臺灣 AI 產業的實踐水平。我們希望以 bottom-up 的方式做出卓越成效，讓政府看見臺灣新創的可能性，進而影響國際布局的策略。

## 你的 run，從這裡開始。

以符合要求的自介 PR 申請，審查通過後取得成員資格。不需要亮眼經歷或完整專案；還在探索，也可以如實說明。

1. 加入 Discord。大家交流、參與活動與找人協作的地方。Discord 是邀請，不是門檻。
2. 到 GitHub 按一顆 Star。用 Star 支持開源筆記，也方便之後找回來。
3. 讀三份文件。創辦人的話、憲法、申請制度：我們想做什麼、共同遵守的原則、怎麼加入。
4. 用 PR 提交自我介紹。寫下你是誰、為什麼加入、想要獲得什麼、想分享什麼，以及可以幫什麼忙、想要幫什麼忙；附一張本人願意公開的照片，自行選擇至少一個 R&R 當 Contributors，並同步分工與成員表。選擇分工不等於接受指定工作。審查通過後，就是成員。
