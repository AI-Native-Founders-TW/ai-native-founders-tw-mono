# 工作流

## 主要放什麼資料

本 package 放志工協作、開源知識整理及 Threads 引流招募客服的運作方式。SOP 說明執行者要做的步驟、要確認的結果、例外處理與交接；要傳送的公版訊息直接放在對應步驟的 payload。

## 與其他 package 的分工

- 工作流所回應的組織目的與上游問題，見[願景和問題](../00-願景和問題/README.md)。
- 成員資格、申請審查、參與及拍板規則，以[制度](../01-制度/README.md)為準；本 package 引用制度。
- 逐人邀請帳號、私訊與私人證據由執行者在有權限的私人 truth 維護，不放進本公開 package。
- 設定與實測進度、提案及變更記於[Kickoff](../../plans/001-Kickoff/plan.md)；會議過程保留在[logs](../../logs/)。
