# 工作流

## 主要放什麼資料

本 package 放志工協作、開源知識整理及 Threads 引流招募客服的運作方式。SOP 說明執行者要做的步驟、要確認的結果、例外處理與交接；要傳送的公版訊息直接放在對應步驟的 payload。

## 文件入口

| 文件 | 主要資料 |
|---|---|
| [志工協作與開源知識]([機制]志工協作與開源知識.md) | 志工時間、申請成本、找人協作與知識取用的 Problem，以及已確認運作和未決構想。 |
| [Threads 引流招募客服 SOP]([機制]Threads引流招募客服SOP.md) | 留言與私訊客服、邀請公版、發送前核對、送出後驗證與邀請帳號 truth 更新。 |

工作流文件的存在不表示平台設定或外部操作已完成；未決安排仍以各檔 Note 為準。
