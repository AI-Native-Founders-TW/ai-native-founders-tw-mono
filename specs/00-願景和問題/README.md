# 願景和問題

## 主要放什麼資料

本 package 放組織想改變什麼、面對哪些 Problem、採取哪些 Principle，以及創辦人對組織目的的原文說明。知識整理的方向及仍待討論的構想也在這裡區分。

## 文件入口

| 文件 | 主要資料 |
|---|---|
| [願景](vision.md) | Problem、Principle、已確認的知識整理方向，以及 Note 中尚未採納的構想。 |
| [創辦人的話](創辦人的話.md) | 創辦人親自撰寫的創辦動機、對參與者的邀請與組織期望；原文的修改與保存依[憲政制度：原文、知識內容與資訊貢獻者](<../01-制度/[機制] 憲政制度.md#原文知識內容與資訊貢獻者>)。 |

Note 中尚未採納的構想不因出現在本 package 或被引用，就成為組織承諾。

原始討論與 credit 見[第一次核心會議記錄](../../logs/20261024-第一次核心會議-會議記錄.md)，不另外維護會議貢獻者彙整檔。
