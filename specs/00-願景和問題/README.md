# 願景和問題

## 主要放什麼資料

本 package 放組織想改變什麼、面對哪些 Problem、採取哪些 Principle，以及創辦人對組織目的的原文說明。知識整理的方向及仍待討論的構想也在這裡區分。

## 與其他 package 的分工

- 組織核心約束、加入與成員參與規則，由[制度](../01-制度/README.md)維護。
- 如何協作、招募、回覆與邀請，由[工作流](../02-工作流/README.md)說明。
- 討論原話與會議過程保留在[logs](../../logs/)，各次提案與變更由[Kickoff](../../plans/001-Kickoff/plan.md)記錄。

## 文件入口

| 文件 | 主要資料 |
|---|---|
| [願景](vision.md) | Problem、Principle、已確認的知識整理方向，以及 Note 中尚未採納的構想。 |
| [創辦人的話](創辦人的話.md) | 創辦人親自撰寫的創辦動機、對參與者的邀請與組織期望；原文依憲法維護。 |

Note 中尚未採納的構想不因出現在本 package 或被引用，就成為組織承諾。
