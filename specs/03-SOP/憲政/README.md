# 憲政 SOP

從想做的事情選入口。這些 SOP 說明成員如何行使權利與接續工作；權限、門檻及期限以[憲法](<../../01-制度/憲法.md>)與[憲政制度](<../../01-制度/[機制] 憲政制度.md>)為準。對應的問題見[憲政制度的問題](<../../01-制度/[問題] 憲政制度.md>)。

| 我想做什麼 | SOP |
|---|---|
| 我想讓組織決定共同事項，或參加投票 | [提出共同事項與參與表決](<[SOP]提出共同事項與參與表決SOP.md>) |
| 我想加入、退出或更換 Contributors 分工 | [加入退出或調整Contributors分工](<[SOP]加入退出或調整Contributors分工SOP.md>) |
| 我想調整 R&R 或任命 Leader | [新增或調整R&R與任命Leader](<[SOP]新增或調整R&R與任命LeaderSOP.md>) |
| 我想撤 Council 或換掉某項 Leader | [罷免Council或替換Leader](<[SOP]罷免Council或替換LeaderSOP.md>) |
| 我想辭任，或需要接手工作與權限 | [辭任Leader與辦理交接](<[SOP]辭任Leader與辦理交接SOP.md>) |
| 我認為資格、審查、計票或執行有錯 | [提出異議與請求覆核](<[SOP]提出異議與請求覆核SOP.md>) |
| 我想退出、保留或恢復成員資格 | [退出保留或恢復成員資格](<[SOP]退出保留或恢復成員資格SOP.md>) |
| 我想修改制度或憲法 | [修改共同制度或提出修憲](<[SOP]修改共同制度或提出修憲SOP.md>) |

任命、罷免與制度修改先讀各自 SOP，再使用共同表決步驟；Contributors 自選、本人辭任及符合條件的退出／恢復，不因此多加一場表決。

申請加入看 [members 說明](<../../../members/README.md>)，審查者看[自介 PR 審查 SOP](<../[SOP]自介PR審查SOP.md>)。首次建立依 [Kickoff 首次建立紀錄](<../../../plans/001-Kickoff/plan.md#首次建立與首屆任命>)，不是一般任命的常設例外。
