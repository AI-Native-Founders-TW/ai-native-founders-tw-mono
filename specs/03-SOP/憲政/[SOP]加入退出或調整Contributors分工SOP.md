# 加入退出或調整Contributors分工 SOP

適用於正式成員想參與、退出或更換 Contributors 分工；不處理 Leader 任免。

## 怎麼做

1. 到 [R&R 入口](<../../02-R&R/README.md>)讀取想參與的職責與目前承接狀態。
2. 選擇要加入或退出的分工。仍保有成員資格時，至少保留一項 Contributors；可以同時參與多項，Leader 也一樣。
3. 在 PR 更新 [R&R assignment](<../../../members/r-and-r-assignment.md>)，說明自己的選擇。自介的 Contributions 可補充能力與意願，但不能代替 assignment。
4. 想接具體工作時，另與該分工確認工作範圍、時間安排及本人接受；只加入 Contributors 不等於承接全部工作。調整分工前，把已接受而尚未完成的工作交代清楚。
5. 請有 repo 合併權限者依有效內容合併，回讀 assignment 與相連的個人成員檔案，核對本人、資格及分工。

## 如何確認完成

assignment 記錄本人選擇，連到正確的個人成員檔案；具體工作的承接另有紀錄。加入 Contributors 不增加治理票數，也不取得 Leader 或平台管理權限。

## 卡住時

- 沒有適合的分工：依[新增或調整 R&R](<[SOP]新增或調整R&R與任命LeaderSOP.md>)提出，不自行建立 Leader 職權。
- 分工 Leader 空缺：可表達參與意願，但不能假稱已有決策者或替別人指定工作。
- 想退出全部分工且不再保留成員資格：走[退出成員資格](<[SOP]退出保留或恢復成員資格SOP.md>)。如果也擔任 Leader，另處理全部職位辭任。

制度依據：[R&R assignment](<../../01-制度/[機制] 憲政制度.md#rr-assignment>)、[工作承接與交接](<../../01-制度/[機制] 憲政制度.md#routine-與-non-routine-responsibilities>)。
