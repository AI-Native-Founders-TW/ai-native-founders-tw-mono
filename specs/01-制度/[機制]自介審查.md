# 自介審查

# Problem

申請制度已有原則，但誰審自介、審查如何進行，以及平台權限如何配合仍未決定。這些安排需要獨立維護，讓招募客服只處理邀請，不自行補訂審查規定。

# Specs

申請者依[申請制度](./[機制]申請制度.md)提交自介 PR，提出申請；審查通過後才成為成員。自介內容、真誠與意圖的審查依據，以及成員資格的取得，均引用該制度。

審查人、審查程序與平台權限的配合尚待確認，列於下方 TODO；尚未確認前，不自行指定審查人、核准申請或授予權限。[既有候選做法](./[機制]申請制度.md#審查安排的候選做法)仍供討論。

自介審查不由 Threads 招募客服追蹤或催辦。
