# 制度

## 主要放什麼資料

本 package 放組織的核心原則、治理規則，以及申請加入、審查、成員資格與參與安排。憲法與具體制度分開維護，讓日常制度的調整依既有程序進行。

## 文件入口

| 文件 | 主要資料 |
|---|---|
| [憲政制度的問題]([問題]%20憲政制度.md) | 治理 Problem、權限、交接及腐敗等預防性案例；完整 Problem Space 已確認；不授予新職權。 |
| [成員識別與資料](<[規格]成員識別與資料.md>) | 永久編號、唯一帳號、自介檔名、配置及資料變更規則；不授予成員資格。 |
| [憲法](憲法.md) | 獨立完整的組織目的、基本權利義務、權力來源及界線、監督與修憲核心；不規定操作方法或首次建立。 |
| [憲政制度](<[機制] 憲政制度.md>) | 憲法範圍內的共同程序：成員資格、R&R 共通責任、投票、罷免、修憲文書、名冊、覆核、資源及權限交接；承接首次建立紀錄，不另授予首次任命權。 |
| [R&R package](<../02-R&R/README.md>) | 各項分工的責任範圍、決策界線、routine、non-routine 與 SOP 引用；每項一份文件。 |

自介審查的操作步驟由 SOP 承接；共同權限由憲政制度維護；實際名單、本人接受與平台配置仍須核對，不從文件成立推定已完成。

申請、成員參與、自介審查、基本參與度與 Council 的共同規則，直接查閱憲政制度的對應章節。

首次採納與首屆任命的條件及實際進度，見 [Kickoff 首次建立與首屆任命](../../plans/001-Kickoff/plan.md#首次建立與首屆任命)。這是一次性成立紀錄，不是後續任命的常設例外。
