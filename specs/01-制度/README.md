# 制度

## 主要放什麼資料

本 package 放組織的核心原則、治理規則，以及申請加入、審查、成員資格與參與安排。憲法與具體制度分開維護，讓日常制度的調整依既有程序進行。

## 與其他 package 的分工

- 組織希望改變什麼與上游 Problem、Principle，見[願景和問題](../00-願景和問題/README.md)。
- 執行制度時如何操作、回覆與交接，見[工作流](../02-工作流/README.md)。工作流引用本 package，不另存第二套資格或治理規則。
- 目前啟動工作的既有修訂提案、理由及憲法檢查見[Kickoff](../../plans/001-Kickoff/plan.md)；後續修憲依[憲法規定](constitution.md#第-20-條修憲建議與修改)辦理。會議原話保留在[logs](../../logs/)。

## 文件入口

| 文件 | 主要資料 |
|---|---|
| [憲法](constitution.md) | 組織目的、非營利性質、基本原則、治理與規範效力。 |
| [申請制度]([機制]申請制度.md) | 自介申請、內容與提交位置、審查及成員資格取得。 |
| [成員參與制度]([機制]成員參與制度.md) | 基本參與度與志工自願貢獻的具體關係。 |

尚未決定的審查安排與參與標準保留於各制度的 Note，不作為已採納規則。
