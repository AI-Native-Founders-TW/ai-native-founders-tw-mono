### 議題 I1（社群媒介換成 Discord）

**問題陳述**
新成員進來後要留在 LINE 群還是 Discord。

**意見原話**

| 發言者 | 原話 | 出處 |
|---|---|---|
| 水球 | 「我覺得我超討厭LINE 但是我們似乎是個必要之惡 因為像LINE大家最常用」 | 0:39:30 |
| 有平 | 「可是覺得LINE很爛」 | 0:39:46 |
| 水球 | 「500人的群確實太小 確實也許不是一個最好的媒介」 | 0:39:53 |
| 有平 | 「然後還有詐騙」 | 0:40:07 |
| 品毅 | 「我覺得可以當LINE LINE當入口 然後Discord當 就是LINE當跳板這樣子 因為不是每個人都有在用Discord」 | 0:40:15 |
| 水球 | 「Discord的黏著會少一點點 但是我相信有創業動力的人 … Discord有點像一個天然的篩選機 所以它被篩選掉了 好像也不用為它心痛」 | 0:40:35 |
| 有平 | 「不應該是那個Widely open的那種 LINE大選 它那個根本不會有黏著度可言」⚠️ | 0:40:46 |
| 有平 | 「必須是這種通話 或者是線下機制 不可能是潛水機制」 | 0:40:59 |
| Jasmine | 「我也投Discord 傳一長串東西的話 好像那個視窗比較好看」 | 0:41:08 |
| 水球 | 「我們剛剛做了一個決議 就是我們要搬到Discord 那LINE群就掰囉」 | 0:41:21 |

**交鋒點**

| 選項 | 內容 | 代價 |
|---|---|---|
| 甲 | 直接搬到 Discord | 黏著會少一點，不用 Discord 的人進不來 |
| 乙 | LINE 當入口與跳板，Discord 當主場（品毅） | 繼續承受 LINE 500 人上限、詐騙與被動潛水 |

讓討論收斂的是水球把進不來的人說成被篩選掉：「Discord有點像一個天然的篩選機 所以它被篩選掉了 好像也不用為它心痛」。

**決策 D1（搬到 Discord）**
- **內容**：社群搬到 Discord，LINE 群不再使用，之後邀請一律用 Discord。
- **拍板**：投票，Discord 四票過半，水球宣布（0:41:14）。
- **理由**：LINE 群 500 人太小、有詐騙、成員被動潛水；Discord「主打一個主動engage 主動高質感engage」。
- **影響**：品毅的 LINE 跳板方案未採納；Discord 的角色在 D4（自介是唯一門檻）再被定為非門檻。

- **影響**：有平提出的激勵機制問題留到後面（見未決事項）；觸發 D3（發 PR 即申請）。

**決策 D3（發 PR 即申請）**
- **內容**：Repo 公開，任何人都能發 PR；新成員發 PR 自介就算申請，核心成員固定去看。審核看自介文章的品質。有平另提「或者是他給了一些什麼貢獻」（0:46:10），未納入本決策。
- **拍板**：品毅、有平同意，水球確認無歧見（0:45:54–0:46:56）。
- **理由**：發 PR 證明他會用 GitHub Repo、有基本的行動門檻，同時減少營運成本。
- **影響**：「誰審」被水球列為 open issue；觸發 D4（自介是唯一門檻）。

**決策 D4（自介是唯一門檻）**
- **內容**：加入的唯一門檻是發自介 PR，通過後就算加入；Discord 會邀請，但不是門檻。
- **拍板**：水球（0:47:48、0:48:40）。
- **理由**：「熱絡是個假議題 真正的議題是 該熱絡的時候 … 你今天發起一個一件有意義的事情 大家都會跟」（0:49:02）；硬把大佬拉進群沒有用，告訴大佬「你只要發個PR 你就是我們的一員」比較好。
