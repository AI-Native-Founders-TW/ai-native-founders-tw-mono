# 客服 SOP 改為人用簡單步驟

## 需求原文

```text
Sop 部分我想改一下格式 
我認爲 現在太多廢話
Think read 等等
我希望是寫給人看的
就很簡單
```

## 使用者目前覺得的 Problem

### SOP 太多指令與重複說明，不適合人閱讀

[客服 SOP](../../specs/02-工作流/[機制]Threads引流招募客服SOP.md#sop)原以 agent 動作標記與多個階段展開，閱讀負擔過高。

## To-Be 目標

1. 用六個簡單步驟說明如何看對話、核對紀錄、回覆、邀請、確認結果及交接。
2. 移除 THINK、READ、WRITE、Phase 與 AI 執行方式的說明；只保留操作者需要的判斷與動作。

## 工程摘要

本輪修改客服 SOP 的呈現方式，並在 AGENTS.md 記錄 SOP 應寫給人看的格式規則；不修改憲法或申請制度，不更新另行維護的 agent skill。保留本人意願、避免重複、送出前後確認、平台限制、隱私與未決事項處理；加入資格仍引用申請制度，不另建規則。鎖定等工具內部細節不放在人用 SOP；多人協作仍須先分工、發送前核對紀錄，原有工具及其鎖定機制不變。

需求原文的口語與換行保留。既有其他未提交修改不納入本輪。

目前 Threads 先前只試到讀取對話與私訊草稿；Discord 邀請、申請審查及整段流程尚未完整實測。本輪僅改文件，未執行外部客服或邀請。
