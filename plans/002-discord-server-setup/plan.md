## 使用者目前覺得的 Problem

### Discord 加入、討論、號召工作與辦活動要容易

（構思中）

新人需要知道怎麼開始；創業者需要容易交流；志工需要容易號召工作；線上與實體活動也需要容易發起與參與。已確認的完整定義見 [Discord 社群 Setup 的 Problem](../../specs/02-工作流/[機制]Discord-社群-Setup.md)。參與者時間有限，重要內容需要能找到，不能以要求每天發言製造熱絡。

頻道名稱使用英文已確認。具體 channels、categories、角色、權限、新人流程及活動安排仍是候選，見[英文配置草稿](../../specs/02-工作流/[機制]Discord-社群-Setup.md#頻道整體配置尚未採納)。

## To-Be 目標

1. 新人從邀請連結進入後，能理解組織目的、找到既有加入方式及提問入口。
2. 參與者容易即時交流，也能持續接續深入問題、經驗與工作號召。
3. 線上與實體活動容易發起及參與，詳情、討論與排程能對應。
4. 在實際目標 server 完成已確認的英文頻道配置、新人引導、必要權限與平台設定，並取得可核對的結果。上述目標均對應 [Discord 社群 Setup 的 Problem](../../specs/02-工作流/[機制]Discord-社群-Setup.md)；目前尚未達成外部設定驗收。
