# 憲法條款編號定位

## 需求原文

> 憲法裡面要 number list 啊，這樣子才可以絕對定位條款

## 使用者目前覺得的 Problem

### 條內內容沒有編號，無法絕對定位條款

[憲法](../../specs/01-制度/constitution.md)各條已有條號，但條內段落未使用 number list，無法清楚引用或連結某一項。

## To-Be 目標

1. 各條的內容使用明列序號的 Markdown number list。
2. 每項提供「條號＋項號」的固定錨點，例如[第十九條（原話保存原則）第三項（創辦人自行修改）](../../specs/01-制度/constitution.md#第-19-條第-3-項)。
3. 既有條號及條標題的連結保留，條內相對指涉改用明確條號與項號。

## 工程摘要

本 Plan 專門修改憲法格式及定位方式。既有中文列舉改為 number list；其他實質段落依原順序編項，序號逐項明寫，不全部寫成同一個數字交給 renderer 推算。每項具有獨立固定錨點。

第二條（公益組織性質）的「前項」、第十五條（共同編輯協作）的「前項」，以及第二十條（憲法修改要求）的「本條」，改用對應條號與項號。第十八條（憲法衝突處理）對第十九條（原話保存原則）第三項（創辦人自行修改）的既有引用，現在有明確項號可核對。

不改條文的實質規則、現行條號、制度分工或未決事項；不重寫歷史原話。接手時願景及憲法有其他未提交修改，另有空檔刪除；本輪期間另有推銷條文的人工修改，皆不納入本輪提交。
