# 制度目錄與憲法核心拆分

## 需求原文

```text
01-憲法改成 01-制度

然後憲法要留下核心和制度

獨立出其他制度文件，好比申請制度

而不是讓憲法這個非核心，未來改憲法很麻煩
```

## As-Is 盤點現況

憲法同時記載組織核心原則、自介 PR、審查細節、基本參與度與制度未決事項，調整申請方式也會變成修憲。志工工作流另有自介提交位置及審查候選安排，規則散在不同文件。

## 使用者目前覺得的 Problem

### 非核心制度不應綁在憲法修改

具體制度應能在不違反組織目的、基本原則與治理規則的情況下獨立調整。[憲法第 20 條（制度修改關係）](../../specs/01-制度/constitution.md#第-20-條修憲建議與修改)界定兩者的修改關係。

## To-Be 目標

1. `specs/01-制度/` 保存[憲法](../../specs/01-制度/constitution.md)、[申請制度](../../specs/01-制度/[機制]申請制度.md)及[成員參與制度](../../specs/01-制度/[機制]成員參與制度.md)。
2. 憲法保留組織目的、非營利、開放與加入原則、志工自願貢獻、協作拍板，以及規範效力與修改規則；申請、審查、參與的具體安排由制度文件維護。
3. 工作流引用制度；既有 Plan 的可點擊路徑同步，歷史敘述及需求原話不改寫。

## 工程摘要

### 工程戰略

本 Plan 專門修改憲法與制度分工。目錄改名後，在憲法保留核心原則，將申請、審查與參與的具體規定及未決事項移到獨立文件，並同步 AGENTS、現行規格及歷史可點擊引用。

| 原有內容 | 本輪落點與處理 |
|---|---|
| 第四條（共同用詞定義）的自介、成員定義 | 定義不再鎖定 PR 技術形式；成員依申請制度加入 |
| 第十一條（自介申請門檻）的具體方式 | 移到申請制度；原條號保留加入原則，沿用原第十二條（真誠意圖審查）的不看背景與篩選意圖原則 |
| 第十二條（真誠意圖審查）的具體判斷與未決審查人 | 移到申請制度；原條號保留制度應遵守的核心原則與引用 |
| 第十三條（志工自願貢獻） | 核心原則留在憲法 |
| 第十四條（基本參與義務）的具體要求 | 移到成員參與制度；原條號保留制度不得強制幫忙的原則與引用 |
| 第二十三條（尚未決定事項） | 未決審查人與參與標準分別移到兩份制度的 Note，不作新的決定 |
| 第二十條（制度修改關係） | 明定制度可依自己的 Plan 修改並接受憲法檢查，不因具體安排調整而修憲 |
| 工作流中的自介位置、內容、審查與參與候選安排 | 移到對應制度，工作流改以引用接續 |

PR 提交、自介審查通過才成為成員、不看文章品質及是否由 AI 撰寫、基本參與度、不強制幫忙等現行規則均保留。本輪不指定審查人、不新增參與指標、不把候選安排採納成規則，也不宣稱平台已設定完成。原有資訊貢獻者名單保留於移入的制度文件。

接手時願景及憲法已有其他未提交修改，另有工作流空檔刪除；本輪以接手快照區分自己的變更，不併入其餘修改。既有歷史 Plan 只修正可點擊連結的目的地，不覆寫當時原話、條號或檢查結果。第六條（已刪判準條文）與第八條（已併收入條文）不恢復；其餘保留條號，以免改動歷史指涉。

### 規格差異

新增申請制度、成員參與制度；憲法保留核心並規範制度關係；兩份工作流改引用獨立制度；目錄及依賴引用同步。皆對應「非核心制度不應綁在憲法修改」。
