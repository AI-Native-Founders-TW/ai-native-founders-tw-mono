

# Kickoff

本 Plan 統一處理 AI-Native Global Founders Speedrun Taiwan 從組織目的、憲法與 Council、成員及 R&R，到 GitHub、Discord、新人加入與活動協作的 launch 準備。Council、憲法與 Discord 都是目前阻擋 launch 的工作，不再作為可以與 Kickoff 無關地結束的獨立 Plan。

本 Plan 尚未完成、尚未 adopt。合併不代表新制度已採納，也不代表平台已重新驗證。文件已寫、制度已確認、平台已設定與流程已實測是不同成果，下文分別記錄。

## 工程摘要

### 工程戰略與相依順序

先補清會影響其他工作的治理依據，同時完成不依賴新治理決策的文件對齊。確認制度後，才把實際人員、平台權限及公開入口對上；最後以一般成員與真實申請驗證整段接續。不能因治理未定停止所有獨立工作，也不能為了先 launch 由 AI 猜測治理權。

| 順序與工作 | 可立即進行 | 需要先成立的依據 | 完成證據 |
|---|---|---|---|
| 整理有效規格與未決 | 核對已有決定、網站落差、文件與平台證據日期 | 現行制度及本 Plan | 沒有把已決事項重問或把未知寫成既定 |
| 完整確認治理 Problem | 檢視具體弊端、相互約束、來源與未知 | 現有 Problem 草稿 | 使用者對完整定義的確認 |
| Council／Leader 共同設計 | Problem 確認後比較整體方案及反例 | 完整 Problem；實際資格與人力資料 | 採納的設計及每項設計理由寫入 specs |
| 憲法與制度核准關係 | 釐清現行條文與需決定的程序 | 不以暫定方案當既有權力 | 必要提案、有效採納依據與逐條檢查 |
| 人員及 routine 接續 | 徵得本人確認、核對未完成事項 | 有效資格與選任方式；具體工作本人接受 | members、assignment 與工作紀錄一致 |
| 網站／repo／onboard 對齊 | 修正已明確的舊文案與路徑 | 正式可用的規格與連結；發布授權 | 網站、repo 與實際釘選全文回讀 |
| 平台權限與一般操作驗證 | 已採納配置可核對；新治理權限須等制度 | 角色及權限來源明確 | 一般成員與管理端證據、失敗接續 |
| 完整加入與活動協作驗證 | 取得真實情境與當事人同意後進行 | 前述入口、審查及承接已可用 | 每段結果與未完成狀態可追溯 |
| Launch 與 adopt 核對 | 最後回讀整份 Plan 的實際成果 | 驗收證據及剩餘限制處置 | 沒有未揭露的阻擋，不以文件數量判完成 |

憲法人工修訂的原專門提案保留全文，包括條號、項號、修訂前後及理由。本輪只合併管理與保存既有提案，不修改憲法、不重開建立期間、不把 Kickoff 直接視為可修改憲法的專門 Plan。未來若需要改憲法，仍受現行專門修憲要求約束；如何在本 Kickoff 管理下合法完成必要修憲，是需處理的程序事項，不能靠改目錄或本段文字免除。

修憲核准人、門檻與生效依據尚未完整訂定；先前提出「三個月內訂定」不能在未核對採納與起算依據時變成正在倒數的規則。此未決不能以本次整併或歷史憲法檢查冒充已解決。

<a id="rr-subpackage-與-responsibilities"></a>

### R&R、成員與必要工作接續

1. 先核對正式成員及申請中資料，不從 GitHub Team 或 Discord 名單補推資格；再依本人確認更新 Leader／Contributors 與交接紀錄。
2. 各 Role 的 routine 應能辨認觸發、時間起算、本人接受、SOP 與完成證據；non-routine 應能辨認事項範圍、需共同決定的影響及停止條件。缺項明示，不替志工預填週期或承接。
3. 活動辦理及 Discord 日常維護與既有 Role 的交界要決定清楚，不從本次誰操作過推定永久責任。
4. Domain-Name 的資產、到期、續約安排及費用決策權需要查明；必要營運工作與仍屬探索的 Gamification 分開確認，不因都有 Role 文件就假定同樣成熟。
5. 網域贊助 credit 的規格已採納，但公司同意、付款、註冊與網站公開尚未完成。依[網域維護](../../specs/01-制度/role-and-responsibility/[Role]Domain-Name維護.md#網域贊助的-credit)取得可核對事實後再公開，不把 credit 規格當成已完成贊助；未完成的資產與公開入口事項納入 launch 核對。
6. 基本參與度除既有 Contributors 選擇外的要求仍未決。可以決定不增加要求，但不能在未決時由執行者自行設出席、發言或工作量門檻。
